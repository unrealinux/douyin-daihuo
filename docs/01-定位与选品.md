# 01 · 定位与选品

## 人群（实测画像，不是猜的）

圈友「自在」23 天后台数据：**女性 65.3%，50+ 占 72%，40+ 占 94%**。
视频号核心用户 30-55 岁（手册口径 35-65 岁），买书的人里 50+ 女性是家庭健康的「代理人」。

她们买书不是给自己消遣，是想：给父母看、跟老伴聊血糖睡眠、转到家族群。几十块钱买的是「我在为家里人操心」。

所以文案不要追网感、梗、快剪反转。要具体、可信、清楚：长寿、睡眠、血糖、防摔、父母健康。

**判断人群是否被触达**：评论区有没有人讲自己的经历、有没有人问书名、有没有人问「适不适合爸妈看」。「讲得不错」不算信号。

## 四大赛道（按视频号适配度排序）

| 赛道 | 内容点 | 变现 | 注意 |
|---|---|---|---|
| 政史社科 | 历史真相、大国博弈、社会规律 | 精装大卷、史学丛书（客单最高） | 敏感话题绕开 |
| 商业经管 | 底层逻辑、思维模型、职场生存 | 经管套装、名人传记 | 佣金最高 |
| 家庭教育/科普 | 高级教育观、儿童脑科学 | 科普百科、青少年读物套装 | 女性用户主场 |
| 健康养生/中医 | 应季食疗、经络、情绪与健康 | 养生百科、食疗套装、情绪书 | **违规高发**，见 `03` |

**已排除**：泛大众励志鸡汤（卷、无信任）、养生极端化（起量即违规）、过时老书（3 年前全网泛滥）、评分 <4.5 的品（投诉退货直接封号）。

## 选品四标准

1. **利润覆盖率**：佣金 >20% 或单笔佣金 >20 元。同一条视频卖 19.9 元绘本（佣金 2 元）和 128 元史学套装（佣金 40-60 元），工作量一样。别卖力气不卖价值。
2. **情绪锚点**：封面标题 3 秒内让人「咯噔」一下。例：「为什么努力没用？」「30 岁后的养生真相」。
3. **视觉延展性**：内容有没有画面感。《抗炎食物》能出健康家庭场景；《高等数学》放弃。
4. **装帧与组合**：设计精致的书比平装更能打动人。组套、赠品、刷边都算增值。

## 选品渠道（按性价比排）

1. **选品中心/精选联盟**：微信 → 发现 → 视频号 → 创作者中心 → 带货中心 → 选品中心。筛「佣金 30% 以上」+「爆款推荐」。
2. **抖音图书音像榜前 50**：抖音卖过 10 万+、视频号还没大 V 在推 = 信息差。抖音火过的品，视频号大概率再火一遍。
3. **出版社直连**：中信、博集天卷、果麦等官方号。2026 年出版社对 AI 博主友好，直接私信说你有 AI 矩阵能力，会寄样书、开定向高佣。
4. **数据罗盘**（视频号创作者中心 → 带货中心 → 数据罗盘）：系统自动匹配同行账号，看同赛道标杆和粉丝画像。

数据罗盘是官方工具，免费且必用。第三方（友望、飞瓜、蝉妈妈）官方在打压，数据有延迟，前期别花钱。

## 套装与定向佣金：最被忽视的两个杠杆

爆款视频是你跟书商谈判的唯一筹码。**出第一单就去联系书商**，别等。

1. 问有没有 2 本/3 本套装 → 单本几十元拉到套装 150-300+，同样播放量 GMV 直接翻倍
2. 申请定向佣金 → 公开 30%-40%，数据好的能到 **45%+**

圈友估算：如果第一轮就做这两步，5 万佣金能做到 6-7 万。他把客单价做到 85.1 元全靠这个。

话术：

> 你好，我在视频号带你们的《书名》，近 X 条视频播放 XX 万、成交 X 单。
> 想问两个事：这本书有 2 本/3 本套装吗？另外能申请定向佣金吗？想长期合作。

## 测号与起号

- 新号拍 2-3 条/天，连续 2-3 天，大部分播放 <100 → 换号，别纠结
- 有老号（2024 年前开通、无违规）直接用，权重比新号好一点
- 起号用最简形式（10 秒内金句、历史人物事迹），先把 1000 粉拿到手
- 号起来后先隐藏/删掉起号用的泛流量视频，再切回图书赛道，用挂车成交重新训练标签
