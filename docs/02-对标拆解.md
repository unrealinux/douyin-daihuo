# 02 · 对标拆解

## 去哪找对标

**优先抖音，其次视频号。** 抖音内容供给比视频号大一个量级，质量也高，先在抖音验证再迁到视频号，确定性更高。

抖音筛选三个维度（圈友「自在」的硬标准）：

1. 点赞 **1 万以上**
2. 图书带货类
3. **评论区有人问书名 / 问怎么买** ← 最重要。用户追问书名，说明已经被种草了

视频号这边搜书名（如《抗炎食物》），选**小爱心多 + 日期最近**的（优先 1 天以内，「爆款还会再爆」）。
视频号图书号很多找不到对应抖音号，这时候只能本地下载视频再提文案。

## 判断「哪条内容正在带来订单」

- **新号**：橱窗总销量低，销量变化直接对得上某条爆款
- **老号**：先截图记销量 → 隔 1-2 小时再看，差值 = 最近在跑的品
- 视频号官方禁止第三方数据平台，所以主要靠手动刷 + 定期统计对标账号橱窗

## 提逐字稿

微信加「元宝」为好友，转发视频并说：

> 提取这个视频里配音的完整内容，要求一字不差，不要总结，不要补全。

拿到后**必须人工过一遍**。ASR 错字集中在：人名、书名、数字、专有名词（「嘌呤」→「飘铃」、「胰岛素」→「衣岛素」）。历史类内容一个人名错了，评论区会打假并限流。

数字要改成中文（十/百/千/万），否则部分 TTS 会把 1000 念成「一零零零」。

## 拆解模板（每条对标复制一份）

```
### 对标 #N
- 来源：抖音/视频号   链接：
- 发布：      播放：     点赞：     评论：      是否新号：
- 对应商品：    销量变化：+___（1-2 小时）    有无人问书名：有/无
- 逐字稿：../conspects/对标N-逐字稿.md

结构拆解
1. 钩子（0-3 秒第一句，逐字抄下来）：
2. 情绪递进（哪几句往上推）：
3. 中腹（故事/论证/正史增量）：
4. 结尾金句 / 解药：
5. 转化位置（第几秒开始带书，怎么带）：
6. 评论区引导方式：
7. 可复用：结构 / 句式 / 情绪点
8. 必须换掉：具体书名、人名、数据、案例
```

## 二创的硬指标：相似度 < 10%

抄的框架是「**锁两头，破中间**」（圈友总结的爆款二创黄金法则）：

- **锁钩子**：前 3-5 秒的核心悬念、反差、认知颠覆，原样或微调强化
- **破中腹**：中段彻底打碎重写，禁止按原文顺叙，加入新的史实/案例/数据
- **锁闭环**：结尾「痛点 → 洞察 → 书是唯一解药 → 互动考题」的结构保留

全文与对标相似度 **> 10% 就重写**。AI 生成也要二次改写，否则触发重复内容降权。

## 存档规范

- 逐字稿存 `../conspects/对标N-YYYYMMDD-关键词.md`
- 一条对标只服务一条二创；同一结构复用不超过 3 次
- 素材转发文件传输助手或统一小号保存
- **不要给自己的视频点赞、不要分享到朋友圈、不要关注自己的号和对标号**——关注关系会分发给微信好友，等于把选品暴露给同行
