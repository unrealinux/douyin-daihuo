# 05 · 数据复盘

## 记录

每条视频一行，写进 `../data/内容台账.csv`。填**发布后 24 小时**的数据，48 小时再补一条进备注（如 `48h: 播放 12.4w 成交 3`）。

字段：`日期, 账号, 序号, 书名, 类型, 对标编号, 播放, 5秒完播率, 完播率, 点击率, 点赞, 转发, 收藏, 评论, 成交单数, 佣金, 涨粉, 备注`

## 阶段 0-5 播放量诊断表（直接对照，别猜）

| 阶段 | 单条播放 | 含义 | 动作 |
|---|---|---|---|
| 0 | 个位数-几十，连续多条 | 账号不正常 | 查违规通知，找原因，解决 |
| 1 | 100-400 | 账号正常，播放正常 | 继续发，优化钩子 |
| 2 | 500-1000 | 上平台推荐了，有流量扶持 | 加大同类选题 |
| 3 | 1000-1w | 多条都到这，说明文案过关 | 可考虑加号、矩阵 |
| 4 | 1w-10w | 带货视频会出单，几十到上百单，佣金几百到几千 | 立刻联系书商：套装 + 定向佣金 |
| 5 | 10w-100w+ | 大爆款，**触发人工审核** | 停手：盯数据、调橱窗、补评论、别发新内容 |

新号 **200-300 基础播放属正常**。

## 数据参考线（圈友实测，可核对）

| 指标 | 参考值 | 低于这条说明什么 |
|---|---|---|
| 无购物车万播单量 | **1.25-1.50 单** | <0.5 = 选品或素材问题，不是量的问题 |
| 商品点击率 | 约 **7.5%** 算不错 | 低 = 人群不匹配 / 书太贵 / 不对路 |
| 5 秒完播率 | **<40% = 钩子不行** | 换开头，戳痛点/抛结果/甩数字 |
| 整体完播率 | 低 = 脚本啰嗦 | 砍废话，每 90-120 秒必须有一个信息转折 |

## 复盘四句口诀（背下来）

> **播放低看开头 3 秒；播放高点击低看钩子；点击高订单低看商品橱窗；订单高播放低保留定时复发。**

第四句的意思：有订单但播放不高的内容，别改，定时重发同样的东西。

## 五个常见现象 → 原因 → 动作

| 现象 | 原因 | 动作 |
|---|---|---|
| 播放持续 <100（连续 2-3 天） | 账号权重低 | 换号，别救 |
| 播放高、零成交 | 内容不像卖书的 / 讲完了方法 / 橱窗对不上 | 补四段结构，检查同款是否第一屏 |
| 播放低、有成交 | 品准，内容没扩散 | 同品再拆 2 条对标重做 |
| 评论区有人问书名但没单 | 承接链路断了 | 置顶评论引导 + 简介引导 + 橱窗排序 |
| 突然掉到几百播放 | 违规降权 | 停更 1 天，查通知，删可疑内容 |

## AI 辅助复盘（把数据喂给 AI）

```
我发了一条关于「___」的视频，数据：播放 5000，5秒完播率 25%，
点赞 50，商品点击 10，成交 1。
我的开头是[粘贴开头]，书中卖点是[___]。
请分析：完播率低在哪一句、点击率低是钩子还是选品问题、
评论区问「___」说明用户真正在意什么。
给我 3 个重写版本的开头，各 ≤16 字。
```

## 每周日复盘

1. 按 `书名` 汇总：哪个品播放/成交比最好 → 下周主推
2. 按 `类型` 对比 A/B 版：B 版连续 5 条零成交 → 回退 A 版
3. 数本周条数，对 100 条目标还差多少
4. **TOP1 单品 GMV 占比 >80% → 立刻孵化第二爆品**，每天留 2-3 条测品视频，短期没单也要测
5. 砍掉本周零成交且播放最低的 1 个选题方向，补 1 个新的

## 别做的事

- 别只盯播放量。没成交的流量不证明链路跑通。
- 别第一周没测够就换书。一本书测满 10 条再判断。
- 别为了日更牺牲合规。一次违规能让爆款流量全废。
