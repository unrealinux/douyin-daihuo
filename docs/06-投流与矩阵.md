# 06 · 投流与矩阵

自然流跑通、且单条稳定出单之后再看这一页。前面没跑通就投流，等于拿钱测自己的菜。

## 一、矩阵（先做，比投流便宜）

### 1 个文案变 3 个号的视频（去重技巧）

- 一段文案生成**两段音频**（一长一短）
- 底图下载**两张不一样的图**
- 用不同音频 + 不同时长做成两条视频 → 分别发 2 个号
- 第 3 个号：拿同一文案走「动态书单」流程，重新分镜生图

文案、图片尽量不要相同，否则系统判同内容，直接降推荐。

### 一鱼多吃（同步抖音/小红书）

跑通闭环之前**不要**跨平台改内容，同一条视频直接分发。跑通之后按平台调性微调：

| 维度 | 视频号（大本营） | 抖音（火力区） | 小红书（品质区） |
|---|---|---|---|
| 侧重 | 信任、深度、养生/社科 | 反常识、强情绪、快节奏 | 审美、生活方式、自我成长 |
| 比例 | 9:16 | 9:16 | 3:4（封面最重要） |
| 长度 | 45-90 秒 | 15-45 秒 | 30-60 秒 |
| 变现 | 橱窗挂车 + 私域 | 橱窗挂车 | 薯条 + 笔记带货 |

### 一人管 10 个号

- 周一：AI 批量产 30 个选题
- 周二：批量产 100 篇差异化文案
- 周三：批量渲染不同风格素材包
- 分发：人工标注书名 + 话题后定时发布
- 10 个号以上：解决网络环境（指纹浏览器 / 二手设备），避免一封百封
- 管理工具：小 V 猫（`https://baoteyun.com/vcat`）

图书赛道封号成本低但连带风险高，一个号违规不影响其他号，这是矩阵的避险价值。

## 二、投流（微付费）

图书适合**投产逻辑**，不是「撬自然流」逻辑：客单 70-100 元，两单回本，ROI 跑正就持续追投。

### 先算账（算不清就别投）

```
盈亏 ROI = 售价 ÷ (售价 - 成本 - 平台扣点 - 预估退货)
```

示例（低客单，仅示范算法）：售价 29.9，代发 2.9，算上扣点和售后退货，盈亏 ROI = 1.26。
ROI 1.26 = 投放利润为 0。要投就投到 1.5 以上。

### 三个投放工具

| 工具 | 目标 | 流量性质 |
|---|---|---|
| 作品加热 | 播放、点赞、关注 | 社区流量（浅层） |
| 商品加热 | 商品点击、成交 | 商业化流量（深层） |
| ADQ | 下单、24h 下单 | 商业化流量（深层） |

投流看**成交密度**，不看完播点赞。

### 六个阶段

1. **测品**：3-5 条计划测 ROI，素材有信心可多给试错成本
2. **放量**：ROI 达标就无限拉计划，无视空耗
3. **压价**：ROI 下滑就降价提升，但要保量级（50 降到 45，就批量拉 45）
4. **卡赔付**：3 单出赔付，全量卡赔付，高投产计划赚、低投产赔，整体稳赚
5. **定向保投产**：加定向拉升 ROI
6. **异常**：不出数据试智能出价 → 双智能测账号是否有问题

几百条计划不逐条盯，用第三方工具（诸葛智投等）看**每小时综合投产**。连续几小时投产和流速都异常才调整。

### 素材比品重要

> 二流的品 + 一流的素材能打爆；一流的品 + 二流的素材不一定能爆。

三级信任模型（促单的核心是信任，不是效果展示）：

1. 一级：普通展示介绍产品（大多数素材在这一级）
2. 二级：真人出镜直接使用产品
3. 三级：塑造人设（「当了十年化妆师，发现很多人不会涂口红」）

挂车素材六要素：画面清晰、字幕大、有讲解且语速慢、广告性足（拒绝泛娱乐）、卖点足、有颠覆认知的点。

### 审核失败的 5 类原因

| 报错 | 处理 |
|---|---|
| 过度营销 | 删逼单话术（工厂直销、今天不买明天涨） |
| 疗效营销 | 删功效承诺（效果明显、立刻见效） |
| 混剪博眼球 | 减少背景/人物切换频率 |
| 预计无法覆盖 | 深度去重（换素材、变速、改字幕样式） |
| 后端产品和视频不符 | 右下角长期挂一张产品主图 |

## 三、什么时候该投

- 自然流出单稳定（万播单量 ≥1.25）
- 有明确的盈亏 ROI 测算
- 有备用账号（投流容易掉购物车，需要多号接）
- 有 3-5 条已被验证的素材，不是拿一条新素材赌
