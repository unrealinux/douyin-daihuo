# 07 · 自动流水线

**顺序不能反**：先手工跑通 10 条，再自动化提文案，最后才自动出片。
圈友原话：工具解决产能，素材解决播放，引导解决订单。这三件事要分开看——产能自动化了，播放和成交也不会自己来。

## 方案 A：零成本版（先用这个）

元宝（提文案 + 拆书）+ 豆包/即梦（生图）+ 剪映（配音剪辑）。
单条 30-60 分钟，一天 2-3 条够用。这套能验证赛道，别跳过。

## 方案 B：全自动出片（圈友「自在」，23 天 5 万佣金那套）

| 步 | 做什么 | 关键参数 |
|---|---|---|
| 1 | **抖音找高赞书单视频**（唯一必须人脑的环节） | 点赞 1 万+、图书带货类、评论区有人问书名 |
| 2 | 提取 + 清洗逐字稿 | ASR 错字极多，让大模型改错别字、重新断句、把「这本书」换成具体书名；数字转中文（否则 TTS 念成个位数） |
| 3 | TTS 合成 | index-tts2 语音克隆效果最好；单次提交限 1000 字，需分段合成；千问/minimax 情感偏弱 |
| 4 | 批量生图 | 按句切片，一句一张，10 分钟视频约 **64 张**；一次请求生成九宫格再自动切割，**成本降 90%**（63 张 <0.5 元） |
| 5 | 合成成片 | Hyperframes 直接输出，不用导入剪映；可一次生成多种风格，矩阵号时自动填充书名/作者/健康声明 |

成本实测：40 条视频，API 总成本约 30 元，单条不到 1 元，15 分钟出片。

**这套的前提**：你有代码能力，且素材/合规问题已经想清楚。不懂代码的人跳过这一整节。

## 方案 C：对标文案库（圈友「千代」，一次 100+ 条）

适合「要抄，但手工提文案太慢」的阶段。

1. 本地批量下载视频号视频：`wx_channels_download`（`https://github.com/ltaoo/wx_channels_download`）
2. 让 Agent（Codex / Workbuddy）建飞书多维表格
3. 表格字段：`文件原名 | 视频标题 | Tag | 书名 | 视频附件 | 提取文案 | 仿写文案 | 配音`
4. 用飞书 AI 字段做「提取原文」和「一键仿写」，只需配置一次

给 Agent 的提示词：

```
帮我安装飞书 CLI：https://open.feishu.cn/document/no_class/mcp-archive/feishu-cli-installation-guide.md

扫描指定文件夹中的全部视频文件，告诉我共识别多少个视频，并确认结果。
创建一张名为「【对标号名字】视频号对标文案库」的飞书多维表格，
字段：文件原名、视频标题、Tag、书名、视频附件、提取文案、仿写文案、配音。
读取每个文件名识别标题和 tag，为前 3 条创建记录并上传视频附件，
让我确认后再处理剩余文件。
```

价值：视频号图书号很多找不到对应抖音号，抖音链接提取法失效，只能本地下载。这套解决的就是这个。

## 方案 D：Skill 化的成片规范（圈友的「60 分钟 → 10 分钟」SOP）

把下面这套规范当 Skill 喂给 Codex / Claude Code，输入对标文案就能出成片素材。

**6 个交付文件**：`新文案.txt`（含气口标点、多音字转译）、`分段内容.txt`（25-35 段，每段 50-85 字）、`分镜提示词.txt`（1:1 对应分段，禁止出现「书」「翻书」描述）、`封面提示词.txt`（3:4 电影海报级）、`封面.jpg`、`发布信息.md`（短标题 <16 字 + 一句话描述 + 评论区置顶带货文案）。

**四条硬指标**：

1. 相似度严格 <10%，超标重写（锁钩子、破中腹、锁解药闭环）
2. 前 3 秒 12-16 字，前 5 秒 20-26 字
3. BGM 三段阶梯：0-15 秒冷酷压制（-22dB）→ 15-90 秒行进暗涌（-20dB）→ 90 秒后绝地爆发（-16dB）→ 结尾围炉解药（-24dB），开启剪映「音频躲避」-6dB、灵敏度 70%
4. 带货段用「声线软着陆」：高潮冷硬定格 → 空 1.5 秒 → 转第一人称私房话 → 语速放慢 10%、音量压低 → 书作为解药给出

**剪映四步调校**：降噪 + 人声增强 30-50% + 音量 +2.5~3.0dB + 多音字修正 + Ctrl+B 在停顿点切音频与分镜磁吸对齐。

## 你现在该做什么

1. 用方案 A 手工做满 10 条，跑完 7 天闭环（`README.md`）
2. 有 1 条出单后，上方案 C，把提文案这一步自动化
3. 稳定日更 5 条以上、且 ROI 算得清，再考虑方案 B/D

跳过任何一步的代价：你不知道数据不好是因为内容、选品还是承接，自动化只会让你更快地拍错方向。
