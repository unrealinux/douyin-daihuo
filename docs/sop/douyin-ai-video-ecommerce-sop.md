## 1. 一句话本质

> **AI 视频带货不是「AI 印钞机」，而是用 AI 把「内容测试」的成本降到极低，
> 再用数据筛出「人群 × 商品 × 场景 × 话术」匹配的组合。**

变现逻辑三句话：

1. 先用内容拿平台流量；
2. 再用内容把「用户需求」和「商品价值」连接起来；
3. 最后通过平台允许的承接方式（橱窗 / 挂车 / 商品卡）完成转化。

真正决定成败的三件事：**内容是否匹配需求 → 商品能否承接需求 → 发布后能否持续复盘优化**。

## 2. 赛道选择（先选对方向，再谈执行）

新手只推两条船，二选一，不要贪多：

| 赛道 | 建议平台 | 内容逻辑 | 用户 | 变现路径 |
|------|----------|----------|------|----------|
| **AI 图书带货** | 视频号（可同步抖音） | 用 AI 生成叙事画面 + 配音，讲有代入感的故事/观点 | 30–55 岁，为养生、传记、历史社科、商业认知付费 | 精选联盟选书 → 加橱窗 → 视频挂车 → 佣金 20%–50% |
| **AI 女装带货** | 抖音（可同步小红书） | 同一件衣服生成通勤/约会/居家多场景展示 | 视觉型消费，看版型/上身/搭配 | 短视频测款 → 挂车成交；小红书种草引流 |

补充赛道（进阶）：AI 短剧带货（视频号，单月 100W GMV 案例）、AI 图文带货。

### 2.1 图书赛道选择的四大标准

1. **高佣金与高溢价（利润标准）**：优先 **客单价 50–200 元**的图书/套装。
   同样做一条视频，卖 19.9 元绘本（佣金 2 元）和卖 128 元史学丛书（佣金 40–60 元）工作量相同。
2. **高信息密度 + 强情绪点**：干货多、观点炸、反常识风险低的类目（社科历史、商业经管、健康养生）。
3. **用户画像匹配**：符合视频号 30–55 岁人群——解决焦虑、看透真相、教育孩子、养生提醒。
4. **低竞争与垂直化**：避开泛大众励志鸡汤，切细分垂直（「只做二战史」优于「做历史」）。

### 2.2 选品三方法

- **看数据**：微信小店带货助手 / 视频号创作者中心「带货中心 → 数据罗盘」（官方免费）；
  第三方平台（友望、飞瓜、蝉妈妈）前期不建议付费。
- **手动刷**：视频号搜关键词 → 看点赞最高的对标 → 判断 AI 能否复刻甚至更高质量的画面。
- **跨平台搬运（信息差）**：抖音「图书音像榜」前 50 → 若抖音已卖 10 万+ 而视频号无大 V 推 → 可做。
- **选品中心**：创作者中心 → 带货中心 → 选品中心，筛「佣金 ≥30%」+「爆款推荐」。
- **对标反查**：刷爆款文案 → 看对标带货的书 → 到选品中心找同款加橱窗。

> 落地动作：选定 1 个赛道 + 准备 **10 本目标图书**作为第一阶段执行目标。

## 3. 完整执行 SOP（六阶段）

```
①选品 → ②对标拆解 → ③二创文案 → ④素材制作 → ⑤发布运营 → ⑥数据复盘
      ↑______________________________________________|
                    复盘结论回流选品/选题库
```

### 阶段 ① 账号与选品准备

- [ ] 注册账号、完成实名与橱窗/带货权限（各平台门槛不同）
- [ ] 确定 1 个赛道（图书 or 女装），锁定平台
- [ ] 建立**爆款选题资产库**（多维表格），字段：
      采集时间 / 标题 / 作者 / 平台 / 口播文案 / 点赞 / 收藏 / 转发 / 评论 / 发布时间 / 封面
- [ ] 用四大标准筛出 10 个目标商品，每个商品记录：客单价、佣金率、单笔佣金、日销、趋势

### 阶段 ② 对标拆解（每天的固定动作）

- [ ] 刷平台，找 **发布时间短、数据爆、主页作品少**的对标视频（= 正在起量的爆款）
- [ ] 提取口播逐字稿（飞书妙记 / 元宝 / 自动化工具），**人工校对错字**
- [ ] 拆解结构：**开场 3 秒钩子 / 核心卖点 / 用户痛点 / 内容结构 / 转化承接方式**
- [ ] 录入选题库，形成可长期复用的资产
- [ ] 红线：对标只用于学习拆解，**禁止直接搬运**

### 阶段 ③ 二创文案（合规是生命线）

- 用提示词对对标文案做**二次改写**，输出标准化素材包：
  - `新文案.txt`（口播稿）
  - `分段内容.txt`（分段脚本）
  - `分镜提示词.txt`（9:16 每镜画面）
  - `封面提示词.txt`（3:4 封面）
  - `发布信息.md`（标题、话题、评论区带货话术）
- **锁两头、破中间**：只借用前 3 秒验证过的爆款悬念，中段彻底打碎、
  按正史/自身逻辑重新组织叙事；**文案相似度压到 10% 以下**（内部硬标准，底线 <30%）
- **史实校验**：AI 易幻觉，生成后人工快速扫读，纠正人名/术语/常识硬伤
- 配音气口（给机器音注入真人感）：
  - `——` 破折号：尾音拖长 1.5 倍，接大转折
  - `……` 省略号：停顿 0.8s、音量下沉 20%
  - 多音字同音转译（削藩 → 靴藩），规避读错字

### 阶段 ④ 素材制作（生成 → 组装 → 人工微调）

标准链路：**AI 生图 / 生视频 → 配音 mp3 → 剪映草稿 → 人工微调 → 导出成片**

- [ ] 分镜提示词 → AI 生图（即梦 / 豆包 / Google Flow），按 `【01】【02】…` 命名
- [ ] 文案 → 配音（剪映云泽大叔等音色 / F5-TTS），导出 `audio.mp3`
- [ ] 图片 + 音频 → 剪映，加运镜/转场/BGM 人声避让
- [ ] **人工微调 2 处**：识别字幕、抽查转场；再导出
- [ ] 红线：**AI 生图严禁画书本封面**（文字扭曲易被判非真实图书展示/侵权）；
      书籍画面后期手动叠加最稳妥

> 自动化只是提速选项，**新人必须先手动跑通一遍闭环**。自动化把单条从 60–80 分钟压到 8–10 分钟。

### 阶段 ⑤ 发布与运营

- [ ] 发布前自检：画面 / 字幕 / 配音 / 商品承接 / 无水印、无错字、无低清、无穿帮、音画同步
- [ ] 备好：标题、封面、话题标签、评论区带货话术
- [ ] 视频挂车 / 橱窗关联商品
- [ ] 发布后维护评论（**黑评也是评**，尽量回复或点赞，不知道回什么回 👍）
- [ ] 文案中可埋「转发给身边的朋友」等引导，转发对视频号权重 > 点赞

### 阶段 ⑥ 数据复盘（图书/视频号指标基线）

| 指标 | 合格线 | 不达标怎么办 |
|------|--------|--------------|
| 播放量 | — | 长期 0–200 → 考虑换号（新号 10–15 天保护期，号有天生残的） |
| **完播率** | **> 20%** | 继续打磨文案（图书带货文案是重中之重） |
| **3 秒播放率** | **> 30%** | 强化前 3 秒钩子，多看对标爆款文案 |
| 平均播放时长 | 越长越好 | 看流失点，强化对应位置的开头/转场 |
| 转发 | 越高越好 | 权重高于点赞，文案埋转发引导 |
| 评论 | 越多越好 | 积极回复，评论能拉动流量 |

> 复盘结论必须回流：数据好的商品/选题「增加素材」，数据差的「及时止损」。

## 4. 风控死亡红线（做图书/国学必看）

| # | 红线 | 后果 | 解法 |
|---|------|------|------|
| 1 | **文案搬运/查重** | 触发风控、限流 | 对标只做学习；二创相似度 <10%，锁两头破中间 |
| 2 | **AI 历史幻觉 / 虚构史实** | 被懂行观众打假、举报虚假宣传限流 | 提示词加「基于正史，严禁拼凑野史」；生成后人工通读 30 秒 |
| 3 | **AI 生图画书本封面** | 判非真实图书展示 / 侵权下架 | 只画意境（深宫夜读、烛影摇红、金戈铁马），书封手动叠加 |
| 4 | **直接搬运对标视频** | 侵权/封号 | 只取结构与方法，重写文案、重做画面 |
| 5 | **背景音乐嘈杂导致转写错字** | 文案出错、被嘲 | 人声干净再转写，产出后必人工复核 |

> 核心原则：**AI 负责 95% 的繁重生产，人工只花 30 秒把住 5% 的真实性底线。**
