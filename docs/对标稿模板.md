# 对标稿模板

`daihuo gen --draft` 吃的就是这个文件。它**只需要逐字稿正文**，不需要你标注结构——
结构拆解是给 B 版文案和人工判断用的，写在下面「拆解」段里，不影响生成。

## 怎么拿到逐字稿（3 分钟）

**方法一：视频号（推荐）**

1. 微信 → 搜索「元宝」→ 添加为好友
2. 视频号里搜书名（如《抗炎食物》），筛**小爱心多 + 1 天以内发布**
3. 把视频**转发给元宝**，发这句话：

   > 提取视频中完整文案，不要总结，要一字不漏

4. 把它吐出来的正文，整段粘进 `conspects/对标01.md`

**方法二：抖音**

1. 抖音筛**点赞 1 万+、图书带货类、评论区有人问书名**
2. 复制链接 → 元宝/豆包/DeepSeek 发「提取这个视频的配音文案，一字不差」
3. 实在提不出来：手打前 5 秒 + 结尾，中间听写要点（够用了，别追求完美）

**方法三：本地下载（视频号号主没绑抖音时）**

`wx_channels_download`（`https://github.com/ltaoo/wx_channels_download`）下载后再提。
这是 `docs/07` 里方案 C 的做法，提 100 条以上时才值得搭。

## 拿到后必须人工过一遍

ASR 错字集中在**人名、书名、数字、专有名词**：

- 「嘌呤」→ 会被识别成「飘铃」，「胰岛素」→「衣岛素」
- 数字改成汉字（一百、三十），否则 TTS 会念成「一零零零」
- 「这本书」这种含糊代词改成具体书名

历史类内容一个人名错了，评论区会打假并限流。
